# 本活 Booktive（ブックティブ）

本の検索・読書記録・好きな作家・図書館予約をひとつにまとめた読書記録アプリです。
ビルド不要のWebアプリ（PWA）で、スマートフォンのホーム画面に追加してアプリとして使えます。

## 機能

| 機能 | 場所 | しくみ |
| --- | --- | --- |
| 本の検索（文字・バーコード） | 検索タブ／右上のバーコードボタン | Google Books API と openBD。カメラで ISBN（978/979）を読み取り |
| 検索からの読書記録 | 本を選ぶと開く詳細画面 | 状態（読みたい／読書中／読了）、読了日 |
| 評価 0.0〜5.0 | 詳細画面 | 0.1刻みのスライダー。「評価しない」も選べる |
| コメント | 詳細画面 | 感想を自由に記入 |
| 分類・作家ごとの表示 | 本棚タブ「作家別」「分類別」 | 分類は openBD の Cコードから自動推定し、手動で変更も可 |
| 好きな作家の登録 | 作家タブ／作家ページ | |
| 好きな作家の新刊紹介 | 作家タブ「好きな作家の新刊」 | 直近6か月の発売本と予約受付中の本 |
| 作家の読破率 | 作家タブ・作家ページ | 文庫本と単行本は同じ作品として数える |
| 読みたい本の登録 | 詳細画面「読みたい」 | |
| 年間・月間の読書記録 | 記録タブ | 月別グラフ、分類の内訳、よく読んだ作家、高評価の本 |
| 図書館予約サイトとの連動 | 詳細画面「図書館で借りる」 | カーリルAPIで貸出状況を確認し、各図書館の予約ページを開く |
| よく行く図書館の登録 | 図書館・賞タブ | 都道府県・市区町村から検索して登録 |
| 直木賞・芥川賞の受賞履歴 | 図書館・賞タブ | 第142回（2009年下期）〜第175回（2026年上期）。読了した作品には印がつく |

## 同梱アプリ: 面接練習ノート

`interview/` フォルダに、採用面接の練習アプリ（回答の音声入力・AI添削・履歴書と職務経歴書からの想定質問づくり）があります。詳しくは [interview/README.md](interview/README.md) を参照してください。

## 起動方法

カメラはHTTPSか `localhost` でしか使えないため、ファイルを直接開かずにWebサーバーで配信してください。

```sh
cd booktive
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

公開するときは、このフォルダをそのまま GitHub Pages や Netlify などの静的ホスティングに置けば動きます。

## 初期設定

「図書館・賞」タブ →「設定」で次のキーを登録します。

- **カーリル アプリケーションキー**（図書館連携に必須）: https://calil.jp/api/dashboard/ で無料発行
- **Google Books APIキー**（任意）: 検索回数が多く制限にかかる場合のみ

## データの保存

記録は端末のブラウザ（localStorage）に保存されます。「設定」→「データのバックアップ」でJSONファイルとして書き出し・読み込みができます。

## 注意事項

- 作家の作品数と新刊は Google Books の登録内容から計算しているため、目安の値です。
- 受賞履歴は `data/awards.js` に入っています。毎年1月と7月の発表後に追記してください。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     デザイン
js/app.js         アプリ本体（検索・記録・作家・統計・図書館・賞）
data/awards.js    芥川賞・直木賞の受賞データ
sw.js             オフライン用のキャッシュ
manifest.json     ホーム画面追加用の設定
```
