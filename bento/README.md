# お弁当ツクール

毎日のお弁当の献立を1週間分まとめて考えるアプリです。ビルド不要のWebアプリ（PWA）で、スマートフォンのホーム画面に追加して使えます。

## 機能

| 機能 | 場所 | しくみ |
| --- | --- | --- |
| 曜日ごとの献立 | 献立タブ | 主食・主菜・副菜2品（スープジャー使用時は汁物も）を曜日ごとに選ぶ。作る曜日は設定で変更 |
| おまかせ（ランダム） | 献立タブ「1週間おまかせ」／各曜日の「おまかせ」 | 同じ週の重複、同じたんぱく源の連続を避け、副菜は赤・黄・緑がそろうように選ぶ。固定したおかずは変わらない |
| 材料からレシピ | 材料からタブ | 冷蔵庫の食材を入れると使えるレシピと足りない材料を表示。「鶏肉」「とりにく」「人参」などの表記ゆれにも対応。食材を優先しておまかせもできる |
| 弁当箱の形と詰め方 | 詰め方タブ | 一段・二段・丸型・曲げわっぱ・スープジャーつき・保温ランチジャーから選ぶと、配置図・詰める順番・彩りチェックを表示 |
| 汁物の提案 | スープジャーつき／保温ランチジャーを選んだとき | 汁物の枠が加わり、おまかせでスープも選ぶ。スープジャーのコツも表示 |
| ヘビロテ登録 | レシピタブの★ | ★をつけたレシピはおまかせで選ばれやすくなる |
| 自分のレシピ登録 | レシピタブ「＋ レシピを登録」 | 料理名・種類・色・材料・作り方。既存レシピをアレンジして登録も可 |
| 買い物リスト | 献立タブ「買い物リスト」 | その週の材料をまとめて表示（調味料・米は除く）。チェックとコピーができる |

## 起動方法

```sh
cd booktive
python3 -m http.server 8000
# ブラウザで http://localhost:8000/bento/ を開く
```

## データ

- 最初から入っているレシピは `js/recipes.js`（主菜28・副菜28・主食12・汁物12）。
- 献立・自分のレシピ・ヘビロテは端末のブラウザ（localStorage）に保存されます。右上の設定からJSONで書き出し・読み込みができます。
