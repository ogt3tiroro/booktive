# 面接練習ノート

企業の採用面接の練習アプリです。Booktive と同じくビルド不要のWebアプリ（PWA）で、このフォルダを配信すればスマートフォンでも使えます。

## 機能

| 機能 | 場所 | しくみ |
| --- | --- | --- |
| よく聞かれる質問への回答入力 | 質問と回答タブ | 自己紹介・志望動機・自己PR など14問を最初から用意。質問の追加も可 |
| 音声入力 | 回答欄の「音声入力」 | ブラウザの音声認識（Web Speech API、日本語）。Chrome・Safari で利用可 |
| 質問の読み上げ | 質問の「読み上げる」 | ブラウザの音声合成 |
| AI添削 | 回答欄の「添削する」 | Claude が添削し、修正後の回答で**変えた箇所を太字**で表示。点数・総評・修正理由・良い点も表示 |
| 履歴書・職務経歴書の読み取り | 書類から質問タブ | PDF・画像・Word（.docx）・テキストを Claude が読み取り、職歴・スキル・深掘りされそうな点を整理 |
| 想定質問の自動生成 | 書類から質問タブ | 読み取った経歴・応募先・面接の段階から質問を生成し、選んで練習リストに追加 |

## 初期設定

「設定」タブで **Claude の APIキー**（https://console.anthropic.com/settings/keys で発行）を登録します。
キーは利用者ごとに入力し、その端末のブラウザにだけ保存されます（公開されるソースコードには入れません）。

## データ

回答・添削結果・書類の読み取り結果は端末のブラウザ（localStorage）に保存されます。
添削・読み取り・質問生成のときだけ、その内容が Anthropic の API に送られます。書類のファイル自体は保存しません。
